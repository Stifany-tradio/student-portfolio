## Built With

- HTML5 – for webpage structure and content
- CSS3 – for styling and layout
- Tailwind CSS – for utility-based styling and responsive design
- Plus Jakarta Sans – for typography
- JetBrains Mono – for monospace text

## Features

- Personal introduction and profile picture
- About Me section
- Skills and learning progress
- Project cards with image previews
- Responsive layout for different screen sizes
- Navigation links to different sections
- Contact information and email link
- Smooth scrolling and hover effects

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the `assets/images` folder contains the required images.
4. Open `index.html` in your browser.
